# QA Automation Portfolio

## О проекте
Автоматизированные тесты для веб-приложения demoqa.com
Написаны на Python с использованием Selenium WebDriver и Pytest.

## Технологии
- Python
- Selenium WebDriver
- Pytest
- Page Object Model (POM)

## Что тестируется
- Заполнение формы (Text Box)
- Проверка полей ввода
- Нажатие кнопок
- Чекбоксы (Check Box)
- Радиокнопки (Radio Button)

## Как запустить
1. Установить зависимости:
pip install selenium pytest

2. Запустить тесты:
pytest test_text_box.py test_button_page.py test_check_box.py test_radio_button.py
